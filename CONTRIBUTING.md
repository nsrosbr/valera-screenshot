# Участь у проєкті

ValeraScreenshot — персональний проєкт одного автора, не продукт компанії. Issue та pull request
вітаються; відповідь може зайняти кілька днів.

## Найкорисніше, що ви можете зробити

**Баг-репорт із кроками відтворення.** Найцінніші звіти в історії цього проєкту приходили
з поля й описували те, чого не бачив жоден тест: «я точно памʼятаю, що ставив чекбокс»
знайшло дефект у 5 із 7 шляхів встановлення. Вкажіть версію (`Про програму`), Windows build,
масштаб екрана (100/125/150 %), кількість моніторів.

**Не** надсилайте знімок екрана з приватними даними — опис словами зазвичай достатній.

## Якщо надсилаєте код

Правила цього репозиторію жорсткі, і вони не про смак:

1. **Гейт мусить лишатися зеленим.** Один запуск, чотири шари:
   ```bash
   powershell -NoProfile -ExecutionPolicy Bypass -File .\test.ps1
   ```
   Він збирає, ганяє твердження ядра, **міряє візуальні пруфи**, керує справжнім застосунком
   справжнім вводом і перевіряє симетрію встановлення/видалення.

   Екран займає лише шар `Drive` (~90 с) — глобальні гарячі клавіші спрацьовують тільки на
   ввід у поточний робочий стіл. Усе інше, включно з візуальними пруфами, працює у вікнах
   поза видимою областю й нічого не перекриває.

2. **Конформність без FAIL:**
   ```bash
   powershell -NoProfile -ExecutionPolicy Bypass -File .\.standard\conform.ps1 -Root .
   ```

3. **Кожна нова обіцянка — з мутацією.** Зелений гейт доводить, що тести ВИКОНАЛИСЬ, а не що
   вони щось стережуть. Якщо ви додали гарантію, додайте в `tools/mutate.ps1` мутацію, яка її
   ламає, і переконайтесь, що гейт від неї ЧЕРВОНІЄ:
   ```bash
   powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\mutate.ps1
   ```

4. **Видима зміна — з рендер-пруфом.** `tools/ProofGate.exe` перезніме `docs/img/`.
   Машина міряє контраст і палітру; **фінальну оцінку дає око** — прикладіть знімки до PR.

5. **`.ps1` — лише ASCII.** PowerShell 5.1 читає їх як ANSI, і один кириличний байт ламає
   парсер. Цей проєкт наступав на це двічі. У `.cs` кирилиця дозволена й потрібна.

6. **Кожен видимий рядок — через `L.S("укр", "eng")`.** Хардкод однією мовою не приймається.

## Чого змінювати не можна без прямої згоди автора

Перелічене нижче — не бюрократія, а речі, які тихо ламають уже встановлені копії:

- **Запінений відбиток сертифіката** (`src/Updater.cs`, `sign.ps1`). Підпис іншим сертифікатом
  безшумно вбиває канал оновлень для кожного встановленого клієнта — а канал і є єдиним
  способом їм про це сказати.
- **URL репозиторію та імена асетів релізу** — з тієї ж причини.
- **Технічна айдентика** (`src/Ident.cs`): назва exe, mutex, ключі реєстру.
- **`src/Updater.cs`** — заморожена копія спільного ядра; правки лише через нього.
- Будь-який **мережевий трафік або телеметрія**. Нуль мережі поза оновленнями — це обіцянка
  продукту, а не деталь реалізації.

Повний список і причини — `CLAUDE.md` §18.1.

## Стиль

Дотримуйтесь стилю сусіднього коду. Коментарі пояснюють **чому**, а не **що**: у цьому
репозиторії коментар зазвичай зберігає інцидент, який породив рядок.
