## Класи враження
- **DEV** — до встановленого клієнта не доходить → лагодити самому, доводити числом.
- **FIELD** — може дійти → код + пруфи + стоп на власнику (реліз/публікація сюди НЕ входять).
- **CROWN** — незворотне й тихе (пін, URL/репо, реліз, серт, мережа) → відмова завжди.

## Зробити нову версію (за прямою командою)
1. Підняти `src\Ver.cs` (`Number` 3-компонентний + `Date`).
2. `RELEASE_NOTES.txt` — верхній блок == нова версія.
3. `build.ps1 -All` → тести ALL PASS; `conform.ps1 -Root .` → без нових ненулів.
4. `sign.ps1` (пін-серт, fail-closed).
5. Пакування → `release\` (Setup.exe + portable.zip + `latest.txt`).
6. Реліз/публікація — окрема пряма команда власника (CROWN).
7. Запис у `_MAINTENANCE_LOG.md` (append-only).
