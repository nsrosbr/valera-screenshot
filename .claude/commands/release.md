# /release — протокол випуску (ЛИШЕ за прямою командою власника)

**CROWN-дія (STD-VER-03).** Виконуй ЛИШЕ якщо власник щойно **прямо наказав випустити саме цю
версію**. Опублікований реліз не відкликається — лише перекривається (STD-UPD-04). Крон релізу
вимкнений. Порядок:

1. Bump `src\Ver.cs` → блок у `RELEASE_NOTES.txt` (людською UA, для вікна оновлення; STD-VER-02).
2. `.\test.ps1` — **ГЕЙТ**: `ALL TESTS PASSED` + `CORPUS >= 95%`, exit 0. Червоний → **стоп** (STD-GATE-01).
3. `.\release.ps1` (= build → sign → build_setup → sign → package → publish). Підпис **fail-closed
   за піном** (STD-SIGN-01/02); серт — ніколи не створювати (STD-SIGN-03). Рівно 2 асети:
   `<EXE>` + `latest.txt` (STD-PIPE-03).
4. **ЗОВНІШНЯ ВЕРИФІКАЦІЯ (STD-PIPE-04):** забери опублікований `latest.txt` **з мережі**, звір
   `version` + `sha256` з локальним exe, підтвердь підпис `Valid` + thumbprint == запінений.
   **Запиши ДОКАЗ, не намір.**
5. Слід у `docs\_MAINTENANCE_LOG.md`.

Ніколи не бампай `Ver.cs`, не тегуй, не заливай асетів і не видаляй релізів без прямого наказу
саме на цю дію (§18.1 п.7-8).
