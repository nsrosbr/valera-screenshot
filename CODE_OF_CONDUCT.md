# Code of Conduct / Кодекс поведінки

**Short version:** be decent. This is one person's project, not a company.

**Коротко:** будьте людяні. Це проєкт однієї людини, не компанії.

## Expected / Що очікується

- Technical disagreement is welcome; personal attacks are not.
- Report a defect, not a person. "This is wrong because X" is useful;
  "whoever wrote this is incompetent" is not.
- Assume the other side had a reason. In this repository most odd-looking lines
  exist because something broke in the field — the comment above them usually says what.

- Технічна незгода вітається; переходи на особистості — ні.
- Повідомляйте про дефект, а не про людину. «Це неправильно, бо X» — корисно;
  «хто це писав, той нездара» — ні.
- Припускайте, що в іншого була причина. У цьому репозиторії більшість дивних на
  вигляд рядків існують тому, що щось зламалося в полі, — коментар над ними
  зазвичай пояснює що саме.

## Not acceptable / Неприйнятно

Harassment, discrimination, sexualised language, publishing someone's private
information, or persistent disruption after being asked to stop.

Цькування, дискримінація, сексуалізована мова, публікація чужих приватних даних
або наполегливе зривання роботи після прохання припинити.

## Enforcement / Виконання

The author moderates. Comments and issues that cross the line are removed;
repeat offenders are blocked. Report privately via [caussa.blog](https://caussa.blog).

Модерує автор. Коментарі й issue, що переходять межу, видаляються; за повторення —
блокування. Повідомити приватно: [caussa.blog](https://caussa.blog).
